# Contributing to METHER OS

We welcome contributions. METHER OS is built by developers 
who want a real personal AI — not a demo.

## How to contribute

1. Fork the repo
2. Create a branch: git checkout -b feat/your-feature
3. Make changes
4. Run tests: cd backend && pytest
5. Commit: git commit -m "feat(scope): description"
6. Push and open a PR

## Commit convention
feat(scope): new feature
fix(scope): bug fix
docs(scope): documentation
ci(scope): CI/CD changes
refactor(scope): refactor
test(scope): tests

## What we need help with
- New tool integrations (Notion, Linear, Slack, Spotify)
- Hindi/regional language TTS voice models
- Better wake word models
- Windows installer improvements
- Mobile bridge (Android/iOS)
- Docker packaging

## Code style
- Python: ruff formatting, type hints everywhere
- TypeScript: strict mode, no 'any'
- Commits: conventional commits only
- PRs: must pass CI before merge

## Questions
Open a GitHub Discussion, not an Issue.
